# 🪖 מילואימנט

רשת חברתית למילואימניקים - פרויקט גמר בקורס פיתוח אפליקציות אינטרנטיות.

> **גרסה 2** נבנית בהדרגה מתוך גרסה 1, וכל חלק עובר סקירה ושיפור לפני שהוא נכנס.

## טכנולוגיות (מתוכננות)
- **שרת:** Node.js + Express, במבנה MVC
- **מסד נתונים:** MongoDB Atlas, דרך Mongoose
- **צד לקוח:** React (Vite), קריאות לשרת עם jQuery Ajax
- **צ'אט:** Socket.io
- **גרפים:** D3.js
